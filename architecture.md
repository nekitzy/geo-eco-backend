\## Потоки данных



1\. \*\*Симуляция датчиков\*\*

&#x20;  mseed\_generator.py → .mseed файлы → mseed\_monitor.py → PostgreSQL



2\. \*\*Реальные данные (Байкал-8)\*\*

&#x20;  Байкал-8 → SeedLink → baikal\_seedlink\_collector.py → PostgreSQL



3\. \*\*Клиентский доступ\*\*

&#x20;  Клиент → REST API / WebSocket → FastAPI → PostgreSQL
